# PitaIA — canal de atualizacoes do app Android

Distribuicao do app PitaIA (antes chamado Pitanga) fora de loja. O codigo-fonte fica em
repo privado.

- **Versao atual:** a indicada em `versionName` no `releases.json`.
- **APK e modelo:** baixados pelos links do `releases.json`. As releases do GitHub guardam
  so versoes antigas (ate a 0.79-beta) e nao devem ser usadas para instalar.

O app le `releases.json` para saber se ha versao nova, mostrar o que mudou e baixar.
