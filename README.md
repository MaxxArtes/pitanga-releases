# Pitanga — canal de atualizacoes

Distribuicao do app Pitanga fora de loja. Aqui ficam apenas o **APK** de cada versao
(assets das releases) e o **changelog** (`releases.json`). O codigo-fonte fica em repo
privado.

O app le `releases.json` para saber se ha versao nova, mostrar o que mudou e baixar.
